Support

Found a bug, stuck on something, or have an idea for making π-Graph better? Write to 3.14graph@gmail.com. It helps to say which device you use and what you expected to happen.

π-Graph has no account and no server, so we can't see your graph. Please don't send it unless you want to; a description is usually enough.

Common questions

My phone doesn't sync with my computer

Both need to be on the same Wi-Fi, and the computer awake with π-Graph open. On the computer, open Sync from the π menu, turn on “Let my other devices sync with this computer”, and choose Pair a phone…. Then scan the code with the phone: the iPhone’s Camera app opens it, or use Scan code… in π-Graph’s own Sync. On Windows, allow π-Graph through the firewall the first time, and make sure your Wi-Fi is set as a Private network.

How do I keep a copy of my graph?

π-Graph takes a backup on its own when you open it, at most once a day and only if something changed. Settings › Data lists them, and Back up now takes another. Save a copy… writes a file you keep wherever you like. On a phone, backups are deleted along with the app, so save a copy before you remove it.

Speak or Type says my AI key was refused

Open AI features from the π menu and check the key, or make a new one on the service’s own site. If the message is about the model instead, leave the model field empty to use the service’s current default.
